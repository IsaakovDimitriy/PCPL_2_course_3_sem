## 📁 Структура репозитория

### [RK1 — Рубежный контроль №1](./RK1/)

**Язык:** Python  
**Вариант:** В  
**Предметная область:** Факультет — Университет

В рамках работы реализованы:

- Классы для хранения данных об университетах и факультетах.
- Связь один-ко-многим с использованием первичных и внешних ключей.
- Связь многие-ко-многим через отдельный класс.
- Три запроса для поиска, обработки и сортировки данных.

**Используемые возможности Python:** ООП, списки, словари, генераторы списков, `min()`, `sorted()`, `lambda`.

**Файлы работы:**
- [main.py](./RK1/main.py) — исходный код программы.
- PDF-отчёт с листингом и результатами выполнения находится в папке [RK1](./RK1/).

## 🚀 Запуск программы

Для запуска необходим Python 3.12

Скачайте репозиторий и выполните команду из его корневой папки:

```bash
python RK1/main.py
```

Программа выводит результаты трёх запросов в консоль.
